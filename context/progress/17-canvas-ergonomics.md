# 17 — canvas-ergonomics

Spec: [`context/feature-specs/17-canvas-ergonomics.md`](../feature-specs/17-canvas-ergonomics.md)

- `17-canvas-ergonomics.md` — complete. Added a floating **control bar** for zoom + undo/redo and wired the same actions to **keyboard shortcuts**. **Control bar** `components/editor/canvas/canvas-controls.tsx` (`CanvasControls`) — a pill (`rounded-full border-surface-border bg-surface/90 backdrop-blur shadow-lg`, matching the shape panel) positioned `absolute bottom-4 left-4 z-10` (bottom-**left**, clear of the bottom-center `ShapePanel`, same `z-10` so it sits above it). Two button groups split by a **thin vertical divider** (`h-5 w-px bg-surface-border` — `--color-surface-border` is registered in `@theme inline`, so both the `border-` and `bg-` utilities generate from it): **zoom** (`ZoomOut` / `Maximize`=fit view / `ZoomIn`, in that order per spec) then **history** (`Undo2` / `Redo2`). Each button is a shared `ControlButton` (`h-9 w-9 rounded-full text-copy-muted hover:bg-elevated hover:text-copy-primary`, `disabled:pointer-events-none disabled:opacity-40` so disabled reads visibly dimmed). **Zoom → React Flow instance**: `useReactFlow<CanvasNode, CanvasEdge>()` drives `zoomIn`/`zoomOut`/`fitView`, each called with `{ duration: ZOOM_DURATION }` (200 ms) for a short smooth animation (React Flow's default is instant). **Undo/redo → Liveblocks history**: `useUndo`/`useRedo` + `useCanUndo`/`useCanRedo` from **`@liveblocks/react/suspense`** (consistent with the room's suspense mode from `11`); the undo button is `disabled={!canUndo}` and redo `disabled={!canRedo}`, so history buttons dim when there's nothing to undo/redo. It's rendered inside `CanvasFlow`'s `relative h-full w-full` wrapper as a sibling of `<ReactFlow>`/`<ShapePanel>` — inside both `ReactFlowProvider` (so `useReactFlow` resolves) and the Liveblocks `RoomProvider` (so the history hooks resolve). **Keyboard shortcuts** `hooks/useKeyboardShortcuts.ts` (`useKeyboardShortcuts<NodeType, EdgeType>({ reactFlow, onUndo, onRedo })`) — made **generic over the node/edge types** because a concrete `ReactFlowInstance<CanvasNode, CanvasEdge>` is *not* assignable to the default `ReactFlowInstance` (RF instances are invariant on their node/edge params via `setNodes`); the generic binds `CanvasNode`/`CanvasEdge` at the call site while keeping the hook decoupled from canvas types. It attaches one `keydown` listener on `window` (cleaned up on unmount) that **first bails when the event target is editable** (`isEditableTarget`: tag is `INPUT`/`TEXTAREA`/`SELECT`, or `isContentEditable`) so typing in a node/edge label never triggers a shortcut, then dispatches: `+`/`=` → `reactFlow.zoomIn`, `-` → `reactFlow.zoomOut` (all no-modifier, `preventDefault`); and under Cmd/Ctrl, `z` → `onUndo` (or `onRedo` when Shift is held), `y` → `onRedo`. `ZOOM_DURATION` is defined and exported once from the hook and imported by the control bar so the keyboard zoom and the button zoom share one animation duration. `CanvasControls` calls the hook with its own `reactFlow` + the Liveblocks `undo`/`redo` handlers, so bar and shortcuts drive identical actions. **Minimap removed** (spec item 6): the bottom-right `<MiniMap>` (and its now-unused `MiniMap` import + the palette props added in the earlier canvas QA Session Note) were deleted from `canvas.tsx` — `<Background>` is now the only RF child. **Scope honored:** the shape panel, node/edge rendering, and the collaborative-state setup (`useLiveblocksFlow`) were all left untouched — the changes to `canvas.tsx` were importing/rendering `<CanvasControls />` and removing the minimap; no extra RF `<Controls>`/panels were added. Verified with `tsc --noEmit`, `npm run lint`, and `npm run build` (all clean). **Not exercised live in-browser** for the same reason as `10`–`16`: the editor is behind the Clerk auth wall and this session has no sign-in credentials, so the zoom-animation, `canUndo`/`canRedo` disabled states, and shortcut dispatch are verified structurally (types/build/lint) and traced against the `@xyflow/react` viewport-helper API + Liveblocks history hooks, not at runtime.
