# 12 — shape-panel

Spec: [`context/feature-specs/12-shape-panel.md`](../feature-specs/12-shape-panel.md)

- `12-shape-panel.md` — complete. Added a bottom shape panel so users can drag shapes onto the canvas to create nodes. **Shared types** (`types/canvas.ts`) were reconciled with `ui-context.md`: `CanvasNodeShape` is now the documented 6-shape set (`rectangle | diamond | circle | pill | cylinder | hexagon`, replacing the placeholder `rectangle | ellipse | diamond` — no other file referenced the old union, so the change was safe), and the file now defines the previously-referenced-but-missing `NODE_COLORS` (the 8 fill/text pairs from `ui-context`) + `DEFAULT_NODE_COLOR` (`NODE_COLORS[0].fill` = `#1F1F1F`) and `NODE_SHAPES` (the 6 shapes each with a sensible `defaultSize`: rectangle `160×80`, pill `160×64` — wider than tall; circle `110×110` — square; diamond `180×110` — slightly larger for label room; cylinder `130×120`; hexagon `150×100`). Also added the drag contract: `ShapeDragPayload` (`{ shape, size }`) + `SHAPE_DRAG_MIME = "application/ghost-shape"`. **Node factory** `lib/canvas-node.ts`: `generateNodeId(shape)` builds ids from `${shape}-${Date.now()}-${counter}` (module-level monotonic counter guarantees uniqueness within a millisecond), and `createCanvasNode(shape, size, position)` returns a `CanvasNode` with `type: CANVAS_NODE_TYPE`, empty `label`, `DEFAULT_NODE_COLOR`, the dragged shape, and `style: { width, height }` (React Flow sizes the wrapper; the renderer fills it). **Shape panel** `components/editor/canvas/shape-panel.tsx` — a floating pill toolbar `absolute bottom-4 left-1/2 -translate-x-1/2 z-10` (rounded-full bordered `bg-surface/90` with backdrop-blur) of six `draggable` icon buttons (lucide `RectangleHorizontal`/`Diamond`/`Circle`/`Pill`/`Cylinder`/`Hexagon`); `onDragStart` writes `JSON.stringify({shape,size})` to `dataTransfer` under `SHAPE_DRAG_MIME` and sets `effectAllowed="copy"`. **Node renderer** `components/editor/canvas/canvas-node.tsx` — the basic custom `canvasNode` renderer: every shape drawn as a simple `rounded-xl` bordered rectangle (fill = `data.color`) with the label centered and four `<Handle>`s (shape-specific SVG visuals deferred, per spec). **Canvas wiring** `canvas.tsx` — split into `Canvas` (now just a `ReactFlowProvider` wrapper) + inner `CanvasFlow` so the drop handler can call `useReactFlow().screenToFlowPosition`. `CanvasFlow` registers `nodeTypes={{ [CANVAS_NODE_TYPE]: CanvasNodeRenderer }}` (memoized), wraps `<ReactFlow>` in a `relative h-full w-full` div with `onDragOver` (preventDefault + `dropEffect="copy"`) and `onDrop` (reads/parses the `SHAPE_DRAG_MIME` payload — bails on missing/malformed, `try/catch` around `JSON.parse`), converts the drop point via `screenToFlowPosition`, builds the node with `createCanvasNode`, and adds it to Liveblocks storage via `onNodesChange([{ type: "add", item: node }])` (verified `applyNodeChanges` in `@liveblocks/react-flow` handles the `"add"` change → writes to the synced `nodes` LiveMap). `<ShapePanel />` renders inside the same wrapper. Verified with `tsc --noEmit`, `npm run lint`, and `npm run build` (all clean). **Not exercised live in-browser** for the same reason as `10`/`11`: no real `LIVEBLOCKS_SECRET_KEY` is provisioned, so the room can't authenticate and the drop→storage-add round-trip is unverified at runtime; the drag payload, coordinate conversion, and node construction are verified structurally via the type/build checks.
